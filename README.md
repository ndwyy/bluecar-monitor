# 小车温湿度监控网页

这是给现有 CH32 小车固件配套的静态监控与驾驶控制页。固件每秒通过 BLE UART Notify 上报：

```text
T=24.68C,H=56.20%
```

网页使用 Web Bluetooth 直接连接小车，无需服务器或手机 App。支持实时温湿度曲线、浅色/深色模式、本机历史保存、CSV 导出和断连保留。

## 使用方法

1. 已部署时，可直接用 Chrome 或 Edge 打开 GitHub Pages 提供的 HTTPS 地址。
2. 本地调试时，可双击 `启动网页.cmd`，或在本目录执行：`python -m http.server 8081`，然后打开 `http://localhost:8081`。
3. 打开电脑蓝牙，让小车上电并开始广播，点击“连接蓝牙”，在浏览器对话框中选择小车。
4. 曲线会在接收 `FFF1` 通知后每秒更新；连接后可按住 `W/A/S/D` 控制前进、左转、后退、右转，松键自动停止。

Web Bluetooth 需要安全上下文；HTTPS 和 `localhost` 都适用，因此不要直接双击 `index.html` 打开。浏览器会记住授权过的设备，首次授权后可直接重新连接。

## 固件对应关系

| 项目 | 值 |
| --- | --- |
| BLE 服务 | `FFF0` |
| 温湿度通知特征 | `FFF1`（Notify） |
| 控制写入特征 | `FFF2`（Write） |
| SHT30 上报周期 | 1 秒 |

键盘控制会映射为固件所需的 `F/B/L/R` 命令；网页在松键、窗口失焦、切换页面或断开蓝牙时发送 `S` 停止命令。小车固件中的失控保护仍会作为第二层保护生效。
